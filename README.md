This repository contains documentation, transcripts, and custom query analysis reports generated during the beta testing of the NASA MCP-GeneLab integration.

## 🔬 Overview & Objectives
As a member of the **NASA OSDR Microbes and Multi-Omics Analysis Working Group**, this workspace documents structured explorations, multi-omics data queries, and comparative spaceflight transcriptomics/epigenetics analyses. The goal is to evaluate AI-assisted knowledge graph queries and standard spaceflight datasets to derive biological insights.

## 🧬 Key Analysis Highlights
- **Circadian Disruption Signature:** Cross-validation of core circadian clock gene suppression (e.g., *Dbp*, *Per2*, *Ciart*) in rodent skeletal muscle studies (OSD-105 / OSD-104).
- **Epigenetic-Transcriptomic Coupling:** Investigating classical epigenetic silencing (promoter hypermethylation leading to transcriptional downregulation) in spaceflight liver samples (OSD-48).
- **Microbiome Profiling:** Evaluating amplicon sequencing data (16S/ITS) comparing spaceflight vs. ground controls in microbial and plant-associated studies (OSD-267).
